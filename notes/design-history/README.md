# design-history

Planning, research and handoff notes from the Claude sessions that built this
repo, copied from the Claude project folder on 2026-10-12 so they travel with
the code. Reference only; where they disagree with the code or a README, the
code wins.

- memory/: session memory (conventions, decisions, state by date; MEMORY.md is the index)
- brain-arch-handoff/: Brain/Pi architecture spec, requirements and results (communiGATR, investiGATR, actuGATR)
- investigatr-handoff/: investiGATR requirements and spec
- coding-standard/: GATR2 coding standard draft with surveys and critiques
- restructure/: naviGATR restructure spec, plan, scripts and WIP patch (paused 2026-09-29); the 80 MB of symbol dump logs were left out
- viz-handoff/, spectu-handoff/: visualizer research, including the controller radio protocol notes with sources
- specta-handoff/: spectaGATR standalone handoff
