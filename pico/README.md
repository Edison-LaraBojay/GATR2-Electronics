# pico

RP2040 software for the Pi HAT.

- [`aggreGATR/`](aggreGATR/README.md): the acquisition firmware (PlatformIO project). It gathers the encoder counts and IMU readings into timed frames for the Pi. Build it from `pico/aggreGATR` with `pio run`.

Component names: [docs/naming.md](../docs/naming.md).
